# حالة مخرجات مشروع IT1515

- [x] **هيكل الموقع والواجهة المشتركة:** يحتوي التطبيق على أكثر من ست صفحات أساسية. تُستخدم ملفات PHP مشتركة عبر `include` أو `require_once` للرأس والتذييل والتنقل. يتضمن الرأس اسم جامعة الباحة والكلية والموقع والشعار، ويتضمن التذييل معلومات تواصل تجريبية وروابطًا مفيدة وحقوق النشر. تتغير روابط التنقل حسب تسجيل الدخول والدور. التصميم بسيط ومناسب لمستوى مبتدئ/متوسط.
- [x] **حسابات الطالب والمسؤول والجلسات:** يتيح التطبيق إنشاء حساب وتسجيل الدخول والخروج مع `session_start()` و`$_SESSION`. يميز بين دوري الطالب والمسؤول، ويحمي صفحات المسؤول على الخادم ويعيد توجيه غير المسؤول. تُخزّن كلمات المرور عبر `password_hash()` ويجري التحقق عبر `password_verify()`. يوجد Cookie دائم لتذكر القسم المفضل لمدة 30 يومًا، إلى جانب جلسة المصادقة.
- [x] **قاعدة البيانات وبيانات التجربة:** تتكون قاعدة MySQL من أربعة جداول مترابطة: `users`, `departments`, `courses`, `enrollments`، بمفاتيح أساسية `AUTO_INCREMENT` ومفاتيح أجنبية وعلاقات مناسبة. يحتوي `database/schema.sql` على أوامر الإنشاء والبيانات التجريبية؛ القاعدة المهيأة تتضمن 10 أقسام و11 مستخدمًا و10 مقررات و20 تسجيلًا.
- [x] **استعراض المقررات والبحث والتفاصيل:** يعرض التطبيق المقررات من قاعدة البيانات بصورة ديناميكية، ويدعم بحثًا بالكلمات عبر `LIKE`، وتصفية حسب القسم، وفرزًا مخصصًا عبر `ORDER BY`، وترقيم النتائج بخمس سجلات للصفحة. يقود اختيار المقرر إلى صفحة تفاصيل تعرض سماته الأساسية والقسم وتاريخ الإضافة.
- [x] **تسجيل الطالب ومقرراتي:** يستطيع الطالب تسجيل نفسه في مقرر وإلغاء تسجيله. تعرض صفحة «مقرراتي» سجلاته باستخدام `INNER JOIN` بين جداول التسجيل والمقررات والأقسام والطلاب، وتُمنع التسجيلات المكررة.
- [x] **إدارة الأقسام والمقررات والتقارير:** تتيح واجهة المسؤول إضافة وعرض وتعديل وحذف الأقسام والمقررات والطلاب والتسجيلات. تعرض صفحة التقارير إحصاءات تستخدم SQL `COUNT` و`GROUP BY`، ومنها عدد الطلاب المسجلين لكل مقرر وقسم.
- [x] **أمن التطبيق والتحقق ومعالجة الأخطاء:** يستخدم التطبيق ملف اتصال مركزيًا عبر PDO، واستعلامات Prepared Statements مع معاملات لكل مدخلات المستخدم، وترميزًا للمخرجات الديناميكية باستخدام `htmlspecialchars()`. يتحقق من مدخلات النماذج في الخادم، ويستخدم رموز CSRF ويعالج الأخطاء برسائل آمنة. اتصال قاعدة البيانات المُدارة يعمل عبر TLS.
- [x] **ملفات تشغيل وتسليم الموقع:** أُنشئ `coursehub-submission.zip`، وملف SQL، ومصدر مخطط ER، وتعليمات تشغيل تتضمن متطلبات PHP وامتداد PDO MySQL وإعداد الاتصال وحسابات التجربة.
- [ ] **التقرير والعرض الشفهي — المرحلة التالية بطلب المستخدم:** إعداد تقرير من 2–3 صفحات يشرح المشروع وتصميم قاعدة البيانات ويضم لقطات شاشة مشروحة ودليل تشغيل وتوزيع مساهمات الفريق، ثم تجهيز عرض حي يقارب 8 دقائق ومناقشة فردية لأعضاء المجموعة.
