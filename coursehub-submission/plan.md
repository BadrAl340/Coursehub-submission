# خطة تنفيذ نظام إدارة المقررات والتسجيل

## الهدف والتنفيذ

بناء تطبيق ويب جامعي لمشروع IT1515 حول المقررات والأقسام وتسجيلات الطلاب. التقنية المطلوبة في المقرر هي PHP باستخدام PDO وMySQL. سيُحافظ على شيفرة مفهومة ومنظمة تناسب مبتدئًا إلى متوسط، مع فصل الاتصال وقواعد الوصول والأجزاء المشتركة والصفحات. سيقرأ اتصال قاعدة البيانات متغير `DATABASE_URL` عند توفره، مع إمكانية ضبط إعداد محلي عبر متغيرات بيئة موثقة؛ لن تُكتب بيانات اعتماد حقيقية في المستودع. يتضمن المشروع ملف SQL قابلًا للاستيراد للهيكل والبيانات التجريبية.

## بنية المشروع

- `public/`: الصفحات التي يفتحها المتصفح، وتشمل الرئيسية والمقررات وتفاصيل المقرر والحساب وتسجيل الدخول وصفحة مقرراتي وصفحات إدارة المسؤول.
- `includes/`: إعداد قاعدة البيانات، الجلسة، التحقق من الأدوار، الترويسة والتذييل والوظائف المشتركة.
- `assets/`: CSS بسيط وأي ملفات واجهة ثابتة.
- `database/schema.sql`: إنشاء الجداول والعلاقات والبيانات التجريبية.
- `README.md`: متطلبات التشغيل والاستيراد وحسابات التجربة.

## الوظائف المطلوبة

استخدام أربعة جداول مترابطة هي `users`, `departments`, `courses`, `enrollments`. توفير حساب طالب ومسؤول مع جلسات، وصلاحيات فعلية للمدير، وتفضيل دائم في Cookie. عرض المقررات من قاعدة البيانات مع البحث والتصفية والفرز وترقيم الصفحات، وتفاصيل مقرر، والتسجيل وإلغاؤه، وصفحة الطالب «مقرراتي» باستعلام `INNER JOIN`. تمكين المسؤول من إدارة الأقسام والمقررات بعمليات الإضافة والعرض والتعديل والحذف، وعرض إحصاءات باستخدام `COUNT` و`GROUP BY`.

## التصميم

ثلاثة اتجاهات أولية واحتمالاتها منخفضة: أسلوب جامعي مسطح وبسيط (0.07)، أسلوب دفاتر دراسية بخطوط يدوية خفيفة (0.05)، أسلوب لوحة إدارية ذات طابع تقني (0.04). الاختيار هو الأسلوب الجامعي المسطح والبسيط، لأنه يطابق طلب المستخدم.

- **الحركة التصميمية:** واجهة أدوات جامعية عملية ومباشرة، بلا زخرفة احترافية أو رسوم متحركة ملفتة.
- **المبادئ:** وضوح الروابط؛ نماذج قصيرة؛ بيانات قابلة للمسح السريع؛ تشابه بصري ثابت بين الصفحات.
- **الألوان:** خلفية فاتحة مع أزرق جامعي هادئ للعناوين والأزرار، ورمادي للنصوص والحدود لتسهيل القراءة.
- **التخطيط:** شريط علوي بسيط، محتوى بعرض مقروء يبدأ بمحاذاة الصفحة، وجداول/بطاقات عادية بحسب نوع المحتوى.
- **العناصر المميزة:** شارة رمز المقرر؛ خط فاصل أزرق رفيع؛ رسائل حالة بسيطة.
- **التفاعل والحركة:** أزرار وروابط واضحة وردود مرئية بعد الإجراء؛ انتقالات خفيفة جدًا أو بلا حركة.
- **الخطوط:** خط نظام شائع يدعم العربية، مع أحجام واضحة للعناوين والنصوص؛ لا يعتمد على تحميل خط خارجي.
- **جوهر العلامة:** أداة مقررات جامعية سهلة الفهم للطلاب والمسؤولين؛ مباشرة، تعليمية، بسيطة.
- **نبرة النص:** تعليمات قصيرة وواضحة. مثال: «ابحث عن مقرر» و«تم تسجيلك في المقرر».
- **الشعار:** اسم نصي «مقرراتي» مع علامة كتاب صغيرة مرسومة بـCSS/نص دون أصول زخرفية خارجية.
- **اللون المميز:** أزرق هادئ موحد للأزرار والروابط والعناوين الثانوية.

## حدود البنية التحتية

المشروع مُهيأ بخدمات خادم وقاعدة بيانات مُدارة؛ قاعدة البيانات متوافقة مع MySQL. بيئة المشروع لا تحتوي PHP مثبتًا حاليًا، لذلك يلزم توفير PHP CLI مع امتداد PDO MySQL لتشغيل هذا التطبيق. لا يُستبدل تنفيذ PHP المطلوب بواجهة غير متوافقة؛ إذا تعذر توفير PHP في بيئة المعاينة، تُسلّم ملفات PHP وSQL كاملة مع تعليمات تشغيل محلية صريحة.
