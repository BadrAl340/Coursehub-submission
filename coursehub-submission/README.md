# نظام إدارة المقررات والتسجيل — IT1515

تطبيق مشروع جامعي بسيط باستخدام **PHP 8+ وPDO وMySQL**. الواجهة باللغة العربية، باتجاه RTL وتصميم مباشر مناسب لمستوى مبتدئ/متوسط.

## المتطلبات

PHP 8 أو أحدث، وامتداد `pdo_mysql`، وMySQL 8 أو MariaDB حديثة. من البيئة الطرفية تحقّق من PHP عبر `php -v` ومن الامتداد عبر `php -m | grep -i pdo_mysql`.

## تشغيل محلي

1. استورد الملف الذاتي `database/schema.sql` بالأمر `mysql -u root -p < database/schema.sql`. ينشئ الملف قاعدة `coursehub` ثم الجداول والبيانات التجريبية.
2. عرّف متغيرات الاتصال في الطرفية، مثل:

```bash
export DB_HOST=127.0.0.1
export DB_PORT=3306
export DB_NAME=coursehub
export DB_USER=root
export DB_PASSWORD='كلمة مرور قاعدة البيانات'
export APP_COOKIE_SECURE=false
```

في بيئة HTTPS أو المعاينة المضمنة اجعل `APP_COOKIE_SECURE=true` (وهو الإعداد الافتراضي). لا تعتمد ملفات PHP على ملف `.env` تلقائيًا؛ عرّف المتغيرات في بيئة تشغيل PHP.

3. شغّل المعاينة من مجلد المشروع: `php -S 0.0.0.0:3000 -t public`.
4. افتح الموقع على `/`.

عند توفر `DATABASE_URL` بصيغة MySQL، يستخدمه التطبيق بدل متغيرات `DB_*`. يمكن تحديد شهادة TLS عبر `MYSQL_SSL_CA` عند حاجة خادم MySQL لذلك.

في بيئة Manus التي توفر `DATABASE_URL`، نفّذ `php database/install.php` مرة واحدة بعد التأكد أن قاعدة المشروع مخصصة لهذا التطبيق. يستخدم المثبّت القاعدة المحددة في `DATABASE_URL` ويتجاهل أوامر إنشاء/اختيار قاعدة `coursehub` الموجودة في SQL المحلي؛ ينشئ الجداول ويضيف بيانات التجربة دون حذف الجداول الموجودة.

## حسابات البيانات التجريبية

- مسؤول: `admin@example.edu` — كلمة المرور: `Admin123!`
- طالب: `student01@example.edu` — كلمة المرور: `Student123!`

تحتوي قاعدة البيانات على أقسام ومقررات وطلاب وتسجيلات تجريبية. الحسابات مخصصة للتجربة بعد استيراد SQL فقط؛ غيّر كلمات المرور عند أي استخدام خارج المشروع الدراسي.

## ما يوفره الموقع

استعراض المقررات مع البحث والتصفية حسب القسم والفرز وترقيم النتائج، صفحة تفاصيل لكل مقرر، تسجيل الطالب وإلغاء تسجيله، صفحة «مقرراتي» باستعلام `INNER JOIN`، وإدارة الأقسام والمقررات والتسجيلات والتقارير من حساب المسؤول. تستخدم الشيفرة PDO prepared statements، وتجزئة كلمات المرور، وجلسات، ورموز CSRF، وترميز HTML للمخرجات.

## صفحات المسؤول

- `/admin/index.php` لوحة المسؤول.
- `/admin/courses.php` و`/admin/course-form.php` إدارة المقررات.
- `/admin/departments.php` إدارة الأقسام.
- `/admin/students.php` إدارة حسابات الطلاب.
- `/admin/enrollments.php` إدارة التسجيلات.
- `/admin/reports.php` الإحصاءات.

يجب استيراد SQL أولًا وتوفير قاعدة البيانات قبل استخدام وظائف الموقع.
